The whole theme is {{ total_files }} files, {{ total_lines }} lines. Your app code is unchanged.

The theme is one app, crud_views_adminlte, listed before crud_views in INSTALLED_APPS. Its page template puts every crud_views page into the page of {{ host.name }} {{ host.version }}, the AdminLTE 4 shell that also renders the dashboard, the user list and this page; whatever it does not override falls through to django-crud-views’ stock Bootstrap 5 templates. Button classes and icons are registered through upstream hooks in apps.py, and menu.py lets the shell’s sidebar menu name ViewSets; no crud_views or adminlte-django code is patched or subclassed. The sales, catalog, roastery and shipping apps never import it: open {% cv_icon "code" "me-1" %}Show code on any of their pages to check.
